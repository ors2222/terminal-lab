# Make Meaning: A Mini Textbook for Design and AI-Assisted Work

How does a plain white T-shirt become an invitation, a visual statement, or a useful case study? This short guide explores how persuasion, brand meaning, and visual design shape what people notice—and how to use those ideas to direct and review AI-assisted work.

Read the chapters in order, or use the links below to jump to a topic. Each chapter builds on the same practical habit: make the intention clear, examine the choices, and keep the work honest.
